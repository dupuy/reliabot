## [1.0.1] - 2026-10-18

### BREAKING CHANGES
- Reliabot updates `dependabot.yml` by creating a new temporary file in the folder and renaming it,
  instead of overwriting an existing file (which may lose or break configuration on partial errors).
  - To get previous behavior (for read-only directories or `dependabot.yml` symlink) add `--insecure`.
